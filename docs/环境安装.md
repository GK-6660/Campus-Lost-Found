# 环境安装

全组只按这一份装。不要用 pip、conda、yarn 或 pnpm，否则每个人的版本会对不上。

数据库和 Docker 现在先不要装。等仓库里有统一的启动方式再一起用。

---

## 1. 先装两个工具

每个人电脑上只需要这两个，装一次即可。

### uv

用来安装 Python 和后端依赖，并锁死版本。

Mac：

```bash
brew install uv
```

没有 Homebrew 时：

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Windows PowerShell：

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

装完新开一个终端，运行 `uv --version`，能打出版本号即可。

### Node.js 22

用来安装前端依赖。请装 **22 的 LTS**，不要装别的包管理器。

从 [https://nodejs.org](https://nodejs.org) 下载 22 LTS。Mac 也可以：

```bash
brew install node@22
```

装完运行：

```bash
node --version
npm --version
```

`node` 应显示 `v22` 开头。

---

## 2. 拉下代码后装依赖

在仓库根目录执行。

后端（Python 3.12 由 uv 安装，不用自己挑 Python 版本）：

```bash
cd backend
uv sync
```

前端：

```bash
cd frontend
npm ci
```

`uv sync` 和 `npm ci` 都会按仓库里锁好的版本安装。不要改成 `pip install` 或 `npm install` 某个包的最新版。

---

## 3. 装好后应有这些

后端，由 `backend/uv.lock` 锁定：

| 包 | 用途 |
| --- | --- |
| fastapi | 接口 |
| uvicorn | 在本地跑接口 |
| pydantic | 校验字段 |
| python-multipart | 上传图片 |
| sqlalchemy | 访问数据库 |
| alembic | 数据库迁移 |
| psycopg | 连接 PostgreSQL |
| pwdlib | 密码哈希 |
| ruff | 统一 Python 格式，只在开发时用 |

前端，由 `frontend/package-lock.json` 锁定：

| 包 | 用途 |
| --- | --- |
| react、react-dom | 页面 |
| antd | 统一的按钮、表单、列表 |
| typescript | 类型检查 |
| prettier | 统一 TypeScript 格式 |

检查：

```bash
cd backend
uv run ruff check app
uv run python -c "import fastapi, sqlalchemy, psycopg, pwdlib; print('backend ok')"
cd ../frontend
npm run format:check
npm run typecheck
```

这四条都没有报错，环境就和大家一致。

Python 版本以 `backend/.python-version` 为准，是 3.12。Node 版本以 `frontend/.nvmrc` 为准，是 22。用 nvm 或 fnm 的人，进入 `frontend` 后执行 `nvm use`。

换行和缩进由仓库里的 `.editorconfig` 和 `.gitattributes` 固定：统一用 LF，前端缩进 2 空格，Python 缩进 4 空格。Windows 上不要改成 CRLF。

代码格式也是锁死的。后端用 Ruff，前端用 Prettier。改完代码后执行：

```bash
cd backend && uv run ruff format app && uv run ruff check app
cd frontend && npm run format && npm run typecheck
```

不要自己换 Black、autopep8、yarn 或 pnpm。

---

## 4. 不要各自加东西

依赖只从仓库根目录下面的两个目录装。不要在仓库根目录运行 `npm install`，那里没有项目。

要新增依赖时，先跟组长说。

后端在 `backend` 目录执行 `uv add 包名`，把 `pyproject.toml` 和 `uv.lock` 一起提交。

前端在 `frontend` 目录执行 `npm install 包名`，把 `package.json` 和 `package-lock.json` 一起提交。

不要提交 `.venv` 和 `node_modules`。这两份是装出来的，别人用上面的命令自己生成。
