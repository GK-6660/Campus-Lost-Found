# 组员操作步骤

把例子里的分支名换成你自己的，例如 `group-b/lost-form`。仓库地址：`https://github.com/GK-6660/Campus-Lost-Found.git`。组长要先把你加进仓库。

Mac 用终端。Windows 用 Git Bash。

---

## 第一次

电脑上先有 Git、uv、Node.js 22。装法见《环境安装》。然后告诉 Git 你是谁，只做一次：

```bash
git config --global user.name "你的名字"
git config --global user.email "你的GitHub邮箱"
```

拉代码并安装：

```bash
cd ~
mkdir -p code
cd code
git clone https://github.com/GK-6660/Campus-Lost-Found.git
cd Campus-Lost-Found
cd backend
uv sync
cd ../frontend
npm ci
cd ..
```

---

## 每次做一件事

```bash
cd ~/code/Campus-Lost-Found
git switch main
git pull
git switch -c group-b/lost-form
```

在这条分支上改代码。不要在 `main` 上改。

改完：

```bash
git status
git add 你改过的文件
git commit -m "说明这次做了什么"
git push -u origin HEAD
```

这条分支以后再推，用 `git push`。不要提交 `.env`、`.venv`、`node_modules`。

然后打开 https://github.com/GK-6660/Campus-Lost-Found ，点 **Compare & pull request**，目标是 `main`，写清做了什么、怎么测的。

组员的申请要另一个人点 **Approve**。组长再点 **Squash and merge**。组长自己的申请不用等批准，直接合并。不要自己点合并。

合并之后：

```bash
git switch main
git pull
git branch -d group-b/lost-form
```

下一件事再从 `git switch main` 和 `git pull` 开始，开一条新分支。

出现 `CONFLICT` 就停下来问组长，不要使用 `git push --force`。
