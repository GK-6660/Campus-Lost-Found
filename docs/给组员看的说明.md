# 我们做的是什么

做一个**校园失物找回网站**。同学用手机或电脑打开我们已有的域名就能用。

我们只做信息平台：帮人对上线索、告诉失主去哪找。不保管实物，不设前台，不做聊天。

---

## 整件事怎么走

1. **丢东西的人登记。** 填类别、颜色、大概时间，再勾选当天去过哪些楼（可以多选、可以按顺序，例如：图书馆 → 教学楼 A → 一食堂）。不确定掉在哪一栋没关系。
2. **捡到的人原位拍照。** 若照片里有姓名、学号、独特图案、码数或序列号，先在页面上涂掉再上传。校园卡、书、衣物、带序列号的电子产品会看到一段说明。系统只保存这张涂过的图，原图不留下，也不发给模型。然后选这是哪栋楼，可以再写一行更准的位置（几楼、靠哪扇窗）。点发布后离开。不用交前台，不用再出来接头。
3. **系统对上线索。** 模型只看这张涂过的照片，读出类别和颜色（人可以改；读不出来就手填）。再拿这些标签，去对失主填的类别、颜色、去过的楼、时间。给出几条最像的，并写明原因。失主看到的是类别、颜色、地点、时间和这张涂过的图。
4. **两个方向都要比。** 先丢后捡：有新照片时，把还没找回的失物再比一遍。先捡后丢：失主一登记，也马上拿已经有的拾获来比。对上了，网站里通知（铃铛），登记页上也能直接看到候选，不只靠点铃铛。
5. **失主去原处看。** 通知里写清去哪栋、为什么像，并说明东西可能已经不在。找到了点「已找回」。没找到点「没找到」，这条失物保持开放，以后有新照片还会再推。
6. **同一条拾获只能有一个人有效。** 有人点了「已找回」，其他人这条候选关掉，并通知一次。乱上传、假照片可以举报，管理员能下架。
7. **太旧或自己不想找了就停。** 过期，或失主撤回，不再重跑、不再发通知。同一条失物和同一条拾获只提醒一次。

分数只用来排序，不表示「这就是你的东西」。登录后只能看到自己的登记、配给自己的候选、以及站内通知。

手机上要能拍照上传、看图、看铃铛。

---

## 一个例子

小林周一丢了黑色耳机。登记时勾选当天去过：图书馆 → 教学楼 A → 一食堂。当时没有人拍照，登记页上先没有候选。

小陈周三在一食堂桌边看到一个黑色耳机盒，就地拍照，地点选「一食堂」，备注「二楼靠窗」，发布后离开。

系统从照片里读出「耳机、黑色」，把还没找回的失物再比一遍，发现一食堂在小林的路线上，于是在网站里通知小林，登记页上也出现这条候选。

小林去一食堂看。找到了就点「已找回」。东西不在了就点「没找到」，以后若再有人拍到类似的，还会再通知他。
